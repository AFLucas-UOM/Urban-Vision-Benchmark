# ============================================================================
# Jetson detection environment (.venv-jetson-detection)
# ============================================================================
# For the MDWD and MTSD supervised-detection tracks of the Jetson edge
# benchmark: Ultralytics YOLO11/12/26 and RF-DETR inference only.
#
# torch / torchvision are DELIBERATELY ABSENT.
#
# On a Jetson, PyTorch comes from NVIDIA's JetPack/L4T wheels and is built
# against the device's CUDA, cuDNN and cuBLAS. Installing a PyPI torch wheel
# here would either fail (no aarch64+CUDA wheel) or silently replace the
# working JetPack build with a CPU-only one. The bootstrap therefore:
#
#   1. creates the venv with --system-site-packages so the JetPack torch stays
#      importable;
#   2. generates a pip constraints file pinning the *installed* torch,
#      torchvision, numpy and opencv versions;
#   3. installs this file with that constraint, so no transitive dependency can
#      pull a different torch in.
#
# Versions mirror Requirements/requirements-traditional-training.txt where an
# aarch64 wheel exists. numpy is pinned to the 1.x series because the JetPack
# torch builds in use are compiled against it.
# ============================================================================
