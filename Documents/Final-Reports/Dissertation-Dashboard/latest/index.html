Project overview

Compare classical supervised detectors, prompt-based foundation models and representation-learning attribute classifiers for two municipal monitoring tasks: kerbside domestic-waste detection (MDWD) and traffic-sign condition assessment (MTSD).

MDWD

30225 images / 211512 boxes / 3598 unique sources (5 classes).

MTSD

2628 QA images / 7266 boxes in groups GRP-1, GRP-2, GRP-3, GRP-5.
